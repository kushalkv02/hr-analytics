# KPI Dictionary

| KPI | Definition |
|---|---|
| Total Employees | Count of employee records |
| Attrition Count | Count where Attrition = Yes |
| Active Employees | Total - attrition count (Attrition = No) |
| Attrition Rate | Leavers / total employees x 100 |
| Retention Rate | Active / total employees x 100 |
| Average Age / Tenure / Monthly Income | Plain averages of age, years_at_company, monthly_income |

**Segment attrition rate** = leavers in the segment / all employees in that segment (never divide by all leavers).
Single snapshot with a historical flag: do **not** present as annualized or monthly turnover.
Always show counts beside rates; flag segments under 30 employees.
